## 📌 Tentang Proyek
**MyWatchList** adalah solusi digital terpusat yang dirancang untuk mengatasi masalah *information overload* bagi para penikmat film dan drama. Aplikasi ini memudahkan pengguna dalam mengelola riwayat tontonan, melacak progres episode secara real-time, memberikan penilaian subjektif, hingga menjelajahi katalog sinema global lintas dekade dan genre tanpa terikat pada satu platform *Video-on-Demand* (VOD) tertentu.

Proyek ini dikembangkan guna memenuhi penugasan mata kuliah **Pemrograman Berbasis Platform (PBP)** Program Studi S1 Teknik Informatika, Universitas Negeri Surabaya.

---

## ✨ Fitur Utama
1. **Portal Jelajahi (ExploreTab):** Katalog VOD modern dengan *Hero Carousel Banner*, kategori tren mingguan, harian, serta filter genre global.
2. **Daftar Pantau Personal (WatchlistTab):** Manajemen status tontonan (*Sedang Menonton*, *Selesai*, *Rencana Ditonton*) dilengkapi bilah progres episode (*progress bar*) dan modal edit interaktif.
3. **Papan Peringkat (RankingTab):** Komparasi 30 karya sinema terbaik berdasarkan rating global dan indeks popularitas dengan penyaring multi-kriteria & negara.
4. **Eksplorasi Dekade & Pencarian Universal:** Fitur penjelajahan film berdasarkan kurun waktu historis (1980-an hingga 2020-an) serta pencarian aktor dan judul film secara instan.
5. **Autentikasi & Profil Pengguna (About Me):** Didukung oleh *Supabase Auth* (surel/kata sandi serta **Google OAuth 2.0**) lengkap dengan dasbor analitik statistik tontonan pribadi.

---

## 🛠️ Tech Stack & Arsitektur
* **Frontend:** Flutter Web (Single Page Application dengan *Clean Architecture*).
* **Backend-as-a-Service (BaaS):** Supabase (PostgreSQL Database, Auth, dan PostgREST API).
* **External Data Provider:** The Movie Database (TMDB) RESTful API.
* **Deployment:** Vercel Hosting.
* **Paradigma Pemrograman:** Pemrograman Berorientasi Objek (PBO) ketat dengan penerapan Enkapsulasi (*Getters/Setters*), *Blueprint Model*, serta *Lazy Loading* menggunakan `ListView.builder`.
